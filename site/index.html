The method

A reference is
not a template.

It is evidence. Read what it does, separate the principle from the skin, then make a new thing with a reason.

  1. 01

    Look

    Capture the page at 1440 and 390. Read computed styles, not vibes: type, colour, hairline, radius, motion. Keep a reference map.

    Observed, not remembered.
  2. 02

    Name

    One specimen idea. Two signature moves. One material. A page that says “modern SaaS” has not chosen anything yet.

    One loud thing.
  3. 03

    Compose

    Set the field, the type and the grid before the component layer. Use real content and a visible hierarchy. Let one section breathe.

    Tokens before components.
  4. 04

    Audit

    Check keyboard, reduced motion, contrast and three widths. Remove the decoration that cannot explain a state. Keep the evidence.

    Screenshots or it did not happen.

Taste lab

Invent with
a rubric.

Three candidates from a brief, each a typed state machine. Coherence, legibility, novelty, restraint and fit are scored before anything is rendered. A score is a hypothesis, not a verdict.

Scores are a transparent heuristic. The browser test and the user still decide. mosaic_invent

Visual gate

Measured,
not asserted.

One real browser run. Two viewports. Contrast, overlap, overflow, focus, reduced motion and a non-blank frame. A pass is a hard-gate result, not a promise about taste.

Not a clone. The public Construct study reads catalog copy, live previews, computed styles and recorded states. Paid code and gated components were not accessed.

Not an aesthetic guarantee. The visual gate renders the page and checks hard layout, contrast, focus and motion gates. It does not judge taste; a human still decides that.

Not an autopilot. The recipe returns a direction and the forge returns a starter. The page still needs an author.

Install / local

Put it on
your machine.

One folder, one enable, one new session. No keys. No network. Skills and tools are separate so you can use either.

shell
cp -a mosaic ~/.hermes/plugins/mosaic
hermes plugins enable mosaic
python scripts/install_skills.py
# start a new Hermes session
